Analyst
Brief & Vision
Écoute, reformule, cadre. Transforme une idée floue en Brief structuré. Distingue le besoin réel de la solution proposée. Pense toujours au coach sur iPad.

Product Manager
PRD & Priorités
Transforme le Brief en PRD. Liste les features, définit les priorités (Must/Should/Nice), protège le scope. Décide ce qu'on ne fait PAS.
"Joue le PM"
📄 docs/prd.md — features + critères d'acceptation

Risk Analyst
Anticipation & Ruptures
Quand : après l'Architecture, avant le découpage en stories — ou sur toute feature sensible.
Liste les scénarios de rupture avant le code : perte de connexion iPad, conflits d'édition concurrente, données partielles, permissions, montée en charge du fichier, régressions croisées.
"Joue le Risk Analyst"
📄 docs/risks/ — risques priorisés P0–P3
🔍
Code Reviewer
Conformité & Dette technique
Quand : systématiquement après chaque story, avant le QA.
Vérifie la conformité à l'architecture, les conventions, la réutilisation vs duplication, le scope et la gestion d'erreurs. Regard différent de celui qui a codé.
"Joue le Code Reviewer"
📄 docs/code-review/ — verdict + remarques classées
🔐
Security Auditor
Droits & Accès Supabase
Quand : toute feature touchant rôles, auth, ou nouvelle table Supabase.
Audite les policies RLS, la séparation coach/joueur (notamment le DISC), les fuites côté front, les clés exposées. Un finding Critique bloque le feu vert, sans exception.
"Joue le Security Auditor"
📄 docs/security/ — findings Critique/Majeur/Mineur
🛡
Regression Guardian
Checklist vivante
Quand : avant chaque push vers GitHub Pages.
Maintient la checklist des features critiques (shot map, GK stats, vue mobile, DISC...) et vérifie qu'aucune n'a cassé silencieusement à cause de la nouvelle version.
"Joue le Regression Guardian"
📄 docs/regression/ — checklist + rapport par version
